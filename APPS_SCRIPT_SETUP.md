# Настройка Apps Script для переаттестации

## 1) Подготовь колонки в листе "Переаттестация"
В первой строке (заголовки) должны быть минимум:
- `Discord ID`
- `Результат`

Рекомендуемые дополнительные:
- `Проводящий куратор`
- `Дата проведения`
- `Кто одобрил`
- `Когда одобрено`

## 2) Установи скрипт
1. Открой Google Таблицу.
2. `Extensions` -> `Apps Script`.
3. Создай/открой файл скрипта и вставь код из `apps-script-reattestation-webhook.gs`.
4. В `CONFIG` измени:
   - `SHEET_NAME` (если вкладка называется иначе)
   - `SECRET_TOKEN` на свой случайный секрет.

## 3) Опубликуй Web App
1. `Deploy` -> `New deployment`.
2. Type: `Web app`.
3. Execute as: `Me`.
4. Who has access: `Anyone` (или `Anyone with link`).
5. Нажми `Deploy` и скопируй URL.

## 4) Пропиши env-переменные на сайте
- `APP_SCRIPT_WEBHOOK_URL` = URL из деплоя Apps Script
- `APP_SCRIPT_WEBHOOK_TOKEN` = тот же токен, что в `SECRET_TOKEN`
- `REATTESTATION_GID` = gid вкладки `Переаттестация`
- `GOOGLE_SHEET_ID` = id таблицы (если отличается от дефолта)

## 5) Проверка
1. На сайте в `Переаттестация` создай заявку.
2. Под админом нажми `Одобрить`.
3. В листе должен обновиться столбец `Результат` значением `сдал`.
4. В панели рядом с заявкой будет `Sheets: отправлено`.

## Что делать, если не работает
- В панели пишет `Sheets: ошибка`:
  - проверь `APP_SCRIPT_WEBHOOK_URL` и `APP_SCRIPT_WEBHOOK_TOKEN`;
  - убедись, что в Apps Script код задеплоен последней версией;
  - проверь точные названия заголовков колонок.
- Не находится строка:
  - проверь, что `Discord ID` на сайте и в таблице совпадает полностью;
  - в скрипте поиск идет по последней подходящей строке.
